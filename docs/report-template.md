# Prof. Maor's report template

Status: **awaiting a sample from Prof. Maor**.

## Authoritative reference

The professor will provide a summary/report he uses today. The final output should resemble that
reference in language, order, headings, clinical terminology, level of detail, and visual appearance.
Several anonymized examples are useful if first visits and follow-up visits use different formats.

Receive examples through an approved private channel. Do not commit real patient information
to this public repository.

## Adaptation process

1. Identify each section and whether it is required, optional, or visit-dependent.
2. Record wording, abbreviations, dates, units, table structure, length and ordering conventions.
3. Match typography, spacing, page size, branding, header/footer and any signature conventions.
4. Define how absent, uncertain, outdated and contradictory information is shown.
5. Produce structured AI output, validated before deterministic HTML/PDF rendering.
6. Retain page-level evidence in the dashboard without disrupting the requested report format.
7. Obtain professor approval of several generated examples before pilot use.

AI draft status must remain visible. Do not reproduce a clinician signature or indicate
approval until the professor has actually reviewed and approved the report.
The current six-section source-cited draft is a provisional format, not the final template.
